# gemini-video：用 Gemini 审查本地视频

当前模型不能直接看视频时，用这个技能把视频交给 Gemini。技能只有一个脚本：`scripts/review-video.mjs`。它上传视频、提出你写的问题、输出 Gemini 的回答，然后删除已上传的文件。

## 使用前确认

1. **用户已同意上传这个文件。** 脚本会把视频发送到 Google 的 Gemini API。用户本人要求审查这个视频，算已同意；其他情况先问用户。
2. **Gemini API key 已配置。** 脚本先读环境变量 `GEMINI_API_KEY`，没有时读 `~/.config/gemini/api-key.env`。两处都没有时脚本会直接报错。让用户在 Google AI Studio 创建 key 并自己配置。不要让用户把 key 贴进对话，也不要读取、打印 key 或 key 文件。
3. **Node 版本不低于 20。** 脚本只用 Node 标准库，不需要安装依赖。

调用按量计费。视频越长、帧率和分辨率越高，费用越高。

## 运行

脚本路径相对本技能目录：

```bash
node scripts/review-video.mjs <视频路径> --question "<审查问题>" [选项]
```

问题较长时，先写进文件，再用 `--question-file <路径>` 传入。

| 选项 | 作用 |
|---|---|
| `--model <id>` | 模型。默认 `gemini-4-carbon`；也可以用环境变量 `GEMINI_VIDEO_MODEL` 指定 |
| `--fps <数字>` | 采样帧率。不设时每秒 1 帧 |
| `--start <秒>`、`--end <秒>` | 只分析这一段 |
| `--resolution <档位>` | 每帧的画面分辨率：`low`、`medium`、`high`、`ultra_high` |
| `--mode agentic` | 让模型自己在时间线上查找。不能和 `--fps`、`--start`、`--end` 同时使用 |
| `--timeout <秒>` | 整个流程的超时，默认 600 |
| `--keep-file` | 分析后不删除已上传的文件 |
| `--json` | 以 JSON 输出，包含用量 |

支持的格式：mp4、mov、webm、mpeg、mpg、avi、wmv、flv、3gp。单个文件不超过 2 GiB。

## 按审查目的选参数

- **整片检查内容和步骤**：用默认参数。每秒 1 帧足够看清画面内容。
- **转场、闪帧、动效节奏**：默认的每秒 1 帧看不到短于 1 秒的变化。用 `--start`、`--end` 截出这一段，再设 `--fps 5` 到 `--fps 10`。先整片跑一次找到可疑时间点，再对这些片段单独高帧率复查。
- **小字、字幕清晰度、界面细节**：加 `--resolution high`。
- **超过 5 到 10 分钟的视频里找某个片段或话题**：用 `--mode agentic`。短视频不要用，它在短视频上更慢，用量也更高。
- **音轨**：Gemini 会同时处理音轨。要检查旁白或配乐时，在问题里明确写出来。本技能没有实测过音轨审查的准确度，报告里要注明这一点。

帧率、片段长度和分辨率决定用量。默认分辨率下每帧约 66 个 token，`--resolution high` 时每帧约 270 个，音轨每秒约 32 个。实测（示例）：15.6 秒的视频用默认参数，视频部分 1136 个 token；其中 3 秒的片段设 `--fps 10 --resolution high`，视频部分 8190 个 token。

## 怎么写审查问题

问题写得越具体，回答越可用：

- 给出对照材料。要检查画面和旁白是否一致时，把旁白稿或字幕文本写进问题。
- 要求带时间戳。写明“每条问题给出 MM:SS 时间戳、看到的画面、影响和修改建议”。
- 一次只问一类问题。内容一致性、字幕、节奏分开问，比一次全问更准。
- 要求区分看到的和推断的。写明“没有看清或不确定的内容标为未确认，不要猜测”。

## 向用户报告

- 注明分析来自 Gemini 对视频的处理，当前模型没有直接看到视频。
- 写明用了哪个模型、帧率和片段范围。脚本输出的第一行有这些信息。
- 默认帧率下没有发现转场问题，不等于没有转场问题。没有做高帧率复查时，把转场和动效标为未审查。
- Gemini 给出的时间戳可能有一两秒偏差。要据此修改视频时，先抽帧核对。

## 出错时

- **提示没有找到 Gemini API key**：请用户配置，不要尝试其他通路。
- **HTTP 402**：项目的预付余额为零。请用户在 Google AI Studio 的项目页充值。
- **HTTP 429 或额度错误**：报告给用户，不要自动重试或换模型。
- **超时**：视频较长时加大 `--timeout`，或者改用 `--start`、`--end` 分段审查。
- **删除上传文件失败**：脚本会在输出里说明。文件 48 小时后自动删除。

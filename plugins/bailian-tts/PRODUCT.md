## Platform

web

## Stack

本地单文件 HTML：原生 HTML / CSS / JS，不引用 CDN 或任何外部资源。一个页面 `studio.html`（配音工作台：开始 / 选音色 / 声音复刻三栏，`#home` / `#voices` / `#clone` 切换）由 `tts.py ui`（别名 `pick-ui`、`clone-ui` 直接打开对应栏）用 Python 标准库 `http.server` 在 `127.0.0.1` 上提供，接口与页面同源，请求带一次性 token。

## Users

- 插件作者本人：技术管理者，做 Vibe Coding 与 FDE 工作，用自己的声音给课件、视频、讲解配音。
- 业务部门同事：插件会交给他们使用，多数不熟悉技术，第一次复刻声音时往往没有专业录音经验，也不会去看命令行输出。

两类人都在 Claude Code / Codex / Pi 的对话里说「复刻我的声音」或「帮我选个音色」后被带到工作台的对应栏，在自己的电脑前独立完成。第一次使用时先落在「开始」：助手在用户默认浏览器打开百炼控制台的 API Key 页（不依赖浏览器自动化工具）并把操作交给用户，用户创建、复制 key 后，由助手或页面读取剪贴板保存。

## Product Purpose

bailian-tts 用阿里百炼 `qwen-audio-3.1-tts-flash` 把文案合成为配音。「开始」负责第一次使用的引导：说明插件能做什么、检查运行环境，并把创建 API Key 这件事拆成三步；成功标准是**不懂技术的人两分钟内配好 key，且 key 不经过对话**。

「声音复刻」负责把「复刻自己的声音」这件事一次走完：准备环境 → 录音 → 复刻 → 试听 → 收藏。

「选音色」负责「从几十个音色里挑出合适的」：用同一句话逐个试听、横向比较，收藏或设为默认。成功标准是**少花几次合成就挑定音色**：同一音色同一句话只合成一次，试听过的音色在清单上留下记录。

「声音复刻」的成功标准：**一次就录出干净可用的声音**。复刻会把录音里的房间混响、底噪和过小的电平一起学进去，录音质量直接决定复刻质量，所以向导的核心价值是在提交前把录音问题拦下来，减少重录和无效复刻。

## Operating Context

- 用户坐在电脑前，可能用笔记本自带麦克风，也可能用领夹麦（如 DJI Mic）或桌面麦。
- 录音在浏览器内完成（MediaRecorder），关闭浏览器自带降噪 / 回声消除 / 自动增益以保留原始音色；也可以选择已有的录音文件。
- 复刻需要 10～30 秒等待（上传百炼临时存储 + 创建音色 + 等待可用），期间页面不能关。
- 向导由 agent 在后台启动，用户点「完成」后服务退出，agent 回到对话汇报结果。

## Capabilities and Constraints

- 录音：麦克风选择、实时电平、计时（10～20 秒最佳，5～60 秒可用）、回放与重录、选择已有文件。
- 录后检查：帧电平 p90 低于 -24 dBFS 提示音量偏小（会带回响），采样峰值 ≥ 0.98 提示削波。
- 复刻：前缀为 1～10 位字母数字；可选降噪与增强。
- 试听：原声与复刻音色对比；可输入自定义句子（支持 `[laughing]`、`[serious]` 等标签）再合成。
- 收尾：设为默认音色 / 加入收藏 / 不收藏 / 删除并重录（删除不可恢复，需确认）；点「完成」关闭服务。
- 选音色：清单按分组（精品中文 / 多语种与方言 / 精品英文 / 其他系统 / 我的复刻 / 已收藏）、性别、关键词筛选；试听句子与指令（≤100 字符，汉字计 2）对所有音色通用；键盘 ↑↓ 换音色、回车试听；收藏 / 取消收藏 / 设为默认直接写 `favorites.txt`；复刻音色可删除（需确认）；没有官方样音，全部现场合成。
- API Key：先向百炼校验（免费的列出复刻音色接口），再原子写入 `~/.dashscope_key`（权限 600）；从剪贴板读取后清空剪贴板；页面与命令输出只显示掩码。未配置时「开始」每 2.5 秒查一次状态，助手在命令行保存后页面自动更新；选音色与声音复刻只显示「去配置 API Key」。
- 接口：`GET /state`、`GET /key`、`POST /key`（`{key}` 或 `{clipboard: true}`）、`GET /mine`、`POST /say`、`POST /fav`（`action` 为 `add` / `rm` / `default`）、`POST /clone`（请求体为音频，query 带 `prefix`、`denoise`）、`POST /delete`、`POST /done`、`GET /audio`，全部带 `?t=<token>`。
- 界面语言为简体中文。

## Product Principles

1. 录音质量先于流程速度：宁可在提交前多拦一次，也不要让用户拿到一个带回响的音色。
2. 给不懂技术的人写：每一步都说清楚该做什么、为什么，技术数值只作为辅助信息。
3. 每个结果都可撤回：不满意可以删除重录，删除前必须确认。
4. 每一栏只做一件事：「开始」只管引导与配置，「选音色」只管挑选和管理音色，「声音复刻」不引入与复刻无关的功能；三栏共用一个服务和一份收藏，切换不丢进度。
5. 密钥不过对话：key 只经剪贴板或页面输入框进入本机文件，助手不读取、不打印完整 key。

## Accessibility & Inclusion

需满足 WCAG AA 对比度；操作需可用键盘完成；状态变化（录音中、复刻中、出错）要有文字说明，不只靠颜色。

录音前准备
  1. 选个安静、软装多的房间窗帘、沙发、衣柜前最好；空房间、浴室、大面积玻璃和白墙会带来回响。关掉空调、风扇和音乐。
  2. 麦克风越近越好领夹麦夹在领口，嘴下方 15～20 厘米；桌面麦离嘴 10～15 厘米。电脑自带麦克风效果最差。
  3. 用你最常用的语气读录音里的语调和节奏会一起被学进去。只录你本人的声音。

第一次开始录音并允许麦克风后，这里会显示设备名称。用外接麦克风时请确认选中的是它。

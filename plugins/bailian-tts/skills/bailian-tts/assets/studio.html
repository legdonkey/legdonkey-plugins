先配好 API Keybailian-tts 用阿里百炼的 qwen-audio-3.1-tts-flash 把文字读成接近真人的配音。第一次用，先花两分钟在百炼控制台创建一个 API Key。
API Key未配置

  1. 打开百炼控制台的 API Key 页在对话里开始时，助手会在你的默认浏览器里打开这一页，然后把操作交给你。也可以自己打开：
    打开百炼控制台
  2. 登录阿里云，创建 API Key确认右上角地域是「华北2（北京）」，点「创建 API Key」；归属账号、业务空间、权限都保持默认即可。
  3. 复制 Key，交给这台电脑保存点 Key 旁边的复制图标。回到对话说「复制好了」，或直接点下面的按钮。

保存前会先向百炼校验一次。Key 只存在这台电脑的 ~/.dashscope_key，权限 600，只有你本人的账户能读；从剪贴板读取后会清空剪贴板。页面和对话里只显示首尾几位。

能做什么

  • 选音色

    68 个系统音色和你复刻的音色在同一张清单里，用同一句话逐个试听、横向比较，满意的收藏或设为默认。

    去选音色
  • 声音复刻

    在浏览器里录 10～20 秒，录完当场质检音量与破音，提交后对比原声和复刻效果。

    去复刻
  • 文案配音

    回到对话说 「用默认音色把这段读出来，语气沉稳一点」，生成 wav；可在文案里加 [laughing]、[serious] 这类标签。

  • 视频配音与字幕

    把多段旁白写成脚本，一次生成分段音频、拼好的整轨和对齐的 SRT 字幕，直接拖进剪辑软件。

  • 选中即朗读

    在任意 App 里选中文字，按一下鼠标按键或快捷键就用默认音色读出来，再按一次停止。仅 macOS。

    去配置

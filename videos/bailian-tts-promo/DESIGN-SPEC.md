# 百炼配音宣传片 · 制作基准

## 模式与产品简报
用户选择自主自由创作。受众是用 Claude Code / Codex / Pi 制作视频、课件、演示的创作者。核心主张：把配音流程交给 AI，从一句需求到可剪辑的音频与字幕。目标约 45 秒，1920×1080 / 30fps，中文。
证据：源项目 PRODUCT.md、README.md、DESIGN.md 与 studio.html。无用户评价、效率倍数或未经验证的模型性能宣传。

## 需求到执行决策
- 真实界面：直接提供原始 studio.html，由隔离演示 HTTP 服务返回静态公开系统音色与虚构状态；不连接用户账号、不读 Key、不改业务代码。
- 声音：沿用当前 Flash 模型，使用现有默认系统音色 xunanchuan_v3.1 为本片配音。文案发送百炼并消耗合成额度。不上传录音、不克隆声音、不修改收藏。
- 复刻：展示真实录音准备页与质检布局，明确“演示数据”，不伪造复刻音频对比。
- 音乐：采用声音产品的近场试听方向，故意不铺 BGM，给人声留完整频段；仅少量转场拟音。没有 BGM，故无需双版本。
- 工程位于 /Users/yangguandao/Projects/bailian-tts-promo，与插件仓库分离。

## 视觉方向
候选：A 安静录音棚；B 技术终端快剪；C 多音色广告拼贴。选择 A，保留石墨底、细字、发丝线、香槟金播放键；拒绝霓虹和无关 3D 道具。
项目已有严格 DESIGN.md，跳过独立 HTML styleframe，使用其原始工作台作为样式基准。
色板：room #111113、panel #1a1b1e、inset #222327、line #2c2e33、ivory #ece8e1、ash #a8a196、champagne #c9b27c、ok #8fcfa6。
字体：PingFang SC / 系统中文无衬线；标题 200–300 字重，正文 400，数字等宽。片中标题 88–132px，说明 32–40px；安全边距 96px。背景纯色，无渐变、光晕和装饰阴影。
动效词：从容、精确、清晰。精致高端与专业信赖之间：主运动 42–48f，Bezier(.4,0,.6,1)，不弹跳；读字 hold ≥45f。没有 shake 或整屏 slam。

## 镜头映射与参考
- 开场主张 → blur-slide / blur-slide。已校验 gallery/api/library.json。实现来源 demos/typography/blur-slide/BlurSlide.tsx；保留三通道同 p、中文按语义拆词、22/30f 入场与主副错峰。
- 参考素材差异：从官方 gallery-media release 下载的 blur-slide.mp4 仍是旧版黑底占位文字；本地准确 BlurSlide.tsx 是新版纸面编辑排版。两者品牌皮肤和文字编排不一致。本片依据当前卡片与准确 TSX 保留三通道同进度语法，再按产品视觉换肤，不声称复刻旧样片外观。
- 选音色 → PageCam 原生截图前推，定制路径，不冒充其它 Gallery 卡。
- 声音复刻 → PageCam 录音准备到质检的匹配剪辑，定制路径。
- 批量产物 → 原创文件排版与逐段轨道展开。这不是产品 UI，是导出成果示意。
- macOS 朗读 → 原创文字选区与按键操作示意，明确平台。
- 品牌收尾 → 安静排版落定，三宿主与仓库入口；不重复开场主张。
原创镜头风险：无现成 demo 调参保证，逐镜抽帧检查文字可读性及停留。

## 分镜（最终帧数在 timeline.ts 中依配音实测冻结）
| # | 时间预算 | 镜头 | 关键动效与信息 |
|---|---|---|---|
| 1 | 0–6s | 把文字，交给声音 | blur-slide；配音开口后小型真实音频包络；从文字到声音 |
| 2 | 6–14s | 先听见，再决定 | 真实选音色页 → 试听台推近；同一句话比较、收藏默认 |
| 3 | 14–23s | 留住你的声音 | 真实录音准备页 → 质检单；录音前准备、录后质检；Flash 专属、需授权 |
| 4 | 23–32s | 从脚本到成片素材 | 三段音轨展开，all.wav / subtitles.srt / 分段 WAV；成果示意 |
| 5 | 32–38s | 选中，按下，听见 | 选区与 ⌃⌥⌘S；仅 macOS、合成后播放，不承诺即时 |
| 6 | 38–45s | bailian-tts | 三宿主兼容与仓库路径，品牌 hold ≥1s |

最终时间轴冻结：0–6 / 6–14 / 14–23 / 23–32 / 32–39 / 39–45 秒。声音复刻段使用原始 DOM 布局，质检“音量合适、没有破音”为明确标注的演示状态，不是测量结果；波形来自本片合成音频。截图内小字为产品纹理，不承担解说；所有叙事另用 62px 字幕承载。

有意识偏离 aesthetic-rules Q8 / S1：本片宣传声音工具，不用发布会群舞、强鼓点和舞台粒子，以安静字标收尾，避免盖过配音与违背产品无光晕规范。Q7 无实体物件特写，C3 无画内 3D 注记，不适用。Q11 以主标题、字幕和行动入口为可读信息；原页面小控件作为截图证据。

接缝采用短淡入与匹配硬切，最多两处轻柔 whoosh。旁白每段独立对齐镜头，字幕独立轨。每镜检查入场、峰值、落定三帧。独立终检须核对宣传边界、素材来源、文字、音频技术指标与工作台 parity。
